## Release focus

The desktop app stops depending on the machine it lands on. On-device transcription, OCR, and scene detection now ship inside the installer — no Python extras, no system packages: a torch-free engine set is compiled into the sidecar, `ffmpeg` and `tesseract` are bundled as pinned, checksum-verified binaries on Linux and Windows, and whisper speech models download on demand from a new model manager with every byte verified against a pinned manifest. From this release forward the app also keeps itself current: a consent-first updater checks the releases feed passively and installs only when you click. And when something breaks in the field, there is finally something to read — rotating logs with emails and home paths redacted at write time, plus a one-click diagnostics export that never touches evidence or the database.

## Highlights

- **On-device AI works out of the box.** The sidecar bundles faster-whisper, pytesseract, and scene detection (no torch — speaker labels remain server-profile). Linux and Windows installers carry pinned, sha256-verified `ffmpeg` (and Linux `tesseract`) builds — a checksum mismatch fails the release build, not your install. Versions and licenses: [`desktop/THIRD-PARTY-BINARIES.md`](desktop/THIRD-PARTY-BINARIES.md).
- **Whisper model manager (Settings → AI).** Models (tiny/base/small) are pinned to exact upstream revisions with per-file checksums; downloads are explicit, verified, and installed atomically — a torn or tampered download can never pass for an installed model. Transcription loads only from these local files: the engine itself can never reach the network. Downloading a model is the one network request on-device transcription ever makes.
- **Engine status you can act on.** Settings → AI shows per-engine availability with the same remedies job failures carry; the transcription probe distinguishes "engine absent" from "model not downloaded" so the fix is always one obvious step.
- **Consent-first auto-updater.** A passive check on launch (and daily) against GitHub Releases; a banner offers the update and nothing downloads or installs without a click. Updates are minisign-verified against a key pinned in the app; the sidecar is stopped cleanly before install. `.deb` installs can't self-update and are never offered one. Note: v0.2.0 and earlier have no updater — this release must be installed manually once; updates apply from here on.
- **Supportability.** The shell and backend keep size-capped rotating logs, with emails and home-directory paths redacted at write time on the desktop profile. Settings → Support offers a one-click diagnostics zip built from a strict allowlist — logs and a version manifest, never evidence, the database, or secrets. Crash files are written on panics. No remote crash reporting, by design.
- **Fixed: engine gating on the desktop.** `GET /capabilities` returned a 500 on every install without the server AI extras (a probe raised on the absent diarization package), so the UI's engine gating never had data on the shipped v0.2.0 desktop build. Caught by the new sidecar smoke check on its first run.
- **Fixed: print styles.** A CSS import-ordering bug silently dropped all print styles from every built stylesheet; court-oriented printing renders styled again.
- **Toolchain: the three held majors landed.** ESLint 10 (flat config), Vite 8 (builds ~4× faster; the esbuild security-advisory override is fully out of the dependency tree), and Tailwind 4 (CSS-first theme, class-driven dark mode preserved). Dependency updates across all ecosystems folded in, including torch 2.12.1.

## Known limitations in 0.2.1

- **Windows OCR needs one manual step.** Only installer-style tesseract distributions exist for Windows, so it isn't bundled; the OCR remedy points at the standard installer. Linux is fully bundled; macOS probes Homebrew for both `ffmpeg` and `tesseract`.
- **Speaker labels (diarization) remain server-profile only.** Deliberate: the dependency drags torch, which the desktop bundle excludes.
- **Windows installers remain OS-unsigned** — SmartScreen may warn on first run, including after updates. Update payloads are still cryptographically verified by the app itself.
- **The Gemini cloud path returns prose, not timed segments**, and inlines the file (~15 MB cap). Carryover from v0.1.17.
- **macOS Intel installer is still not produced** (Apple Silicon only). Carryover from v0.1.1.
- **Desktop sidecar cold-start on Windows can still take 15–25 s.** Carryover from v0.1.3.

## Security

- Whisper model downloads are pinned to exact upstream revisions with per-file SHA-256 verification and atomic installs; bundled host binaries are pinned and verified the same way at build time (GPL source availability for ffmpeg is documented in the third-party notice).
- The updater verifies every payload against a minisign public key pinned in the app; checks are passive and installs are consent-gated. This adds one documented background egress (the release-feed check), spelled out in [`docs/desktop-lite.md`](docs/desktop-lite.md) alongside the existing opt-in list.
- Desktop logs are redacted (emails, home paths) before they touch disk; the diagnostics export is allowlist-only and operator-initiated. One known gap is tracked publicly: raw sidecar stderr mirrored into shell logs is not yet redacted (#299).
- Report vulnerabilities privately by emailing the maintainer — do not open a public issue.
