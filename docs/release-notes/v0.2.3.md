## Release focus

Reach and polish. Evidence review gains a **deterministic clarity-assist** panel (classical ffmpeg filters — brightness, contrast, gamma, denoise, sharpen, deinterlace, upscale — with a suggest step, never AI), a **Cmd+K command palette** that searches across every case you belong to, and a **real audio waveform** drawn from the actual samples instead of a synthetic sine wave. Underneath, the clustering read path stops issuing a query per asset, a benchmark harness guards against that regressing, and two long-standing correctness/privacy gaps are closed: server-profile downloads no longer break their own presigned URLs, and raw sidecar output is scrubbed before it reaches the diagnostics logs.

## Highlights

- **Deterministic enhancement (Review → enhancement panel).** Adjust brightness, contrast, saturation, gamma, denoise, sharpen, deinterlace, and integer upscale; a **Suggest** button analyzes the clip and pre-fills values with a plain-language reason for each (e.g. "video is dark → gamma 1.4"). Every enhancement is a regenerable derivative whose exact ffmpeg parameters are recorded and shown in a provenance popover. Filters are **classical and deterministic only — no AI, no super-resolution** — stated in the panel.
- **Cmd+K command palette.** Search cases, assets, timeline events, and annotations from anywhere. Results are strictly scoped to the cases you're a member of — the search resolves your memberships first, so you never see another user's content (admins see all). Plus quick navigation actions.
- **Real audio waveform.** The waveform is now extracted from the actual audio (peak envelope via ffmpeg) rather than a `Math.sin` placeholder; when peaks aren't available the UI says so honestly instead of drawing a fake wave.
- **Faster clustering.** The absolute-time computation behind correlation/clustering issued three database queries per asset; it now issues a constant four regardless of case size, with a new `(case_id, capture_time)` index (migration 018). A benchmark harness (`backend/tests/perf/`) pins this: a query-count guard fails CI if the per-asset pattern ever returns, and an opt-in latency benchmark reports p50/p95.
- **Fixed: server-profile downloads.** Asset and export download links appended an unsigned `?disposition` query parameter, which broke MinIO's SigV4 signature and returned 403 on the server profile. The download filename is now signed into the presigned URL (`response-content-disposition`) instead.
- **Fixed: log redaction gap.** The backend scrubs emails and home paths from its structured logs, but raw sidecar stderr (tracebacks, crashes) reached the desktop shell's rotating logs — and the diagnostics export — unredacted. The shell now applies the same scrub before anything is written.
- **Test coverage.** Backfilled the genuinely-untested frontend hooks and components; the stale coverage trackers are closed.

## Migrations

- **018** adds the `(case_id, capture_time)` index on `assets`. Server deploys: `alembic upgrade head`. Desktop installs migrate themselves at boot.

## Install

- **Desktop Lite (individuals):** update in place from the in-app updater, or download the installer from this release's assets. No factory reset required.
- **Server (organizations):** see [`docs/prod-deploy.md`](docs/prod-deploy.md); run `alembic upgrade head` for migration 018.

## Known limitations in 0.2.3

- **Enhancement suggestions analyze a leading sample.** The heuristic reads the first few seconds of a clip; a video whose characteristics change partway through may warrant manual adjustment.
- **Waveform peaks are produced at ingest.** Assets ingested before this release show the honest "waveform unavailable" state until re-ingested; an on-demand backfill is a follow-up.
- **Global search is substring (ilike) v1.** A full-text (FTS5/tsvector) upgrade is a separate design note — it needs post-`create_all` DDL and a schema-parity allowlist.
- **Windows OCR still needs a manual tesseract install; diarization remains server-profile only; Gemini transcription returns prose, not timed segments; macOS Intel installer is not produced.** Carryovers from prior releases.

## Security

- Global search enforces case membership at the query level (a single audited boundary); a non-member sees nothing, and the isolation is covered by an end-to-end test.
- Presigned downloads no longer carry an unsigned query parameter — the disposition is signed into the URL, so tampering with it invalidates the signature.
- Sidecar stderr is redacted (emails, home paths) before it reaches the shell's logs or the operator-initiated diagnostics zip.
- Report vulnerabilities privately by emailing the maintainer — do not open a public issue.
